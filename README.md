# All Out Site — starter

This repository is the starting point of a website made with **All Out Site**, Apeiralia's
website builder. It holds a whole small site, as plain files:

```
site.toml            the site: its name, languages, look, menu, contact details, footer
pages/<slug>.toml    one file per page: its title, its description, its blocks in order
media/               its pictures
```

## Making your own site from it

1. On All Out Site, choose **« Continuer avec GitHub »**, then **« Créer mon site »**.
2. GitHub opens this template to make **your own repository** from it, in your account (private by
   default). Your site lives there, every change in its history.
3. Then give All Out access to that one repository (the « All Out Farm » GitHub App): the builder
   reads and writes your site with your own sign-in, and Apeiralia's Worker publishes it.

You change it in the builder (pages of blocks, in your languages, with an assistant that proposes
changes for you to confirm), or by hand: every file is text.

The files of this starter are given to start your own site: once your repository is made from it,
its content is yours.
